# model/ — 정적 자산

평가 서버에서 `data/`는 주최측이 마운트하므로(실제 평가 입력이 `data/test.jsonl.gz`로 주어진다)
우리가 만든 파생 자산은 여기에 둔다. `script.py`는 `PPS_ASSET_DIR`(기본 = `script.py` 옆의 `model/`)에서 읽고,
파일이 없거나 깨져도 기본값으로 실행을 계속한다.

| 파일 | 내용 | 다시 만들기 |
|---|---|---|
| `조문발췌.json` | 항목그룹별 근거 조문 발췌. 법령 전문 5MB를 프롬프트에 넣을 수 없어 필요한 조만 뽑았다. | `python3 tools/build_조문발췌.py` |
| `경쟁제품코드.json` | 세부품명번호 → 중소기업자간 경쟁제품 여부 (615코드). v10~v13 판정의 결정론적 조인. | `tools/` 참조 |
| `게이트.json` | 고시금액 등 메타 게이트 상수와 dev 검증 기록. | 직접 수정 |
| `임계값.json` | 항목별 위반 판정 임계값. | 오프라인 튜닝 결과 반영 |

## 주의

- **`게이트.json`을 고치면 반드시 `python3 tools/audit_gates.py`를 통과시킬 것.** 게이트는
  재현율을 깎지 않는다는 전제로 쓰는 장치다. 실제로 v6·v7·v8에 금액 게이트를 걸었다가 dev 양성
  7건을 죽인 적이 있고, 그 검사에서 잡았다.
- **`임계값.json`은 런타임에 바꾸지 말 것.** 대회 규칙이 샘플 간 예측 의존을 금지한다. 테스트셋
  분포를 보고 임계값을 정하는 것은 규칙 위반이다.
- 제출 ZIP에 LLM 가중치·LoRA 어댑터를 넣을 수 없다. 여기에는 정적 자산만 둔다.
