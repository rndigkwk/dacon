## 3. 코드에 박아 넣은 상수와 근거 조문

`model/lexicon.py` 의 모든 수치는 배포된 법령패키지에서 가져왔다. 파일 안에도 같은 주석이 달려 있다.

| 상수 | 값 | 근거 |
|---|---|---|
| `GOSI_STATE_GOODS` | 2억 3천만원 | 국가계약법 제4조①  재정경제부 고시(2026-439) 1.가 물품 및 용역 |
| `LOCAL_REGION_LIMIT_DEFAULT` | 5억원 | 지방계약법 시행규칙 제24조제2호 나목 |
| `LOCAL_REGION_LIMIT_ENGINEERING` | 3억 3천만원 | 지방계약법 시행규칙 제24조제2호 가목 |
| `LOCAL_REGION_LIMIT_SAFETY` | 1억 5천만원 | 지방계약법 시행규칙 제24조제2호 가목 단서 |
| `PANRO_SMALL_LIMIT` / `PANRO_SME_LIMIT` | 1억원 / 2억 3천만원 | 판로지원법 시행령 제2조의2제1항 제1·2호 |
| `JOINT_MIN_SHARE` 국가 10% | 10% (±20% → 하한 8%) | (계약예규) 공동계약운용요령 제9조제5항 나목 |
| `JOINT_MIN_SHARE` 지방 5% | 5% (±20% → 하한 4%) | 지방자치단체 입찰 및 계약 집행기준 제6장 제2절 1-나-2) |
| `BRIEFING_LEAD_DAYS` | 40 / 20 / 10일 | 지방자치단체 입찰시 낙찰자 결정기준 제7장 제3절 2-다 |
| `BRIEFING_NOTICE_DAYS` | 7일 | 같은 조항 |
| 판로지원 예외 | 시행령 제2조의3 | 판로지원법 시행령 제2조의3 제1항 |
| 경쟁제품 소기업 특례 | 제7조의2 | 판로지원법 제7조의2 제1항 |
| 지방+소액수의 예외 | v2·v6·v7·v8 배제 | 항목표.json 비고 "지방 + 소액수의 가능" |
| `SW_TIERS` | 20·40·80억 | 항목표.json v20 비고 (현재 판정 로직에서 미사용) |

`WIDE_REGIONS`(17개 시·도명)·`REGION_ALIAS`는 지방계약법 시행규칙 제25조제3항의 "시·도" 구분과
meta `제한지역코드목록` 에 나타나는 표기를 코드로 옮긴 것으로, 외부에서 수집한 데이터 자산이 아니다.
`KW_*` 키워드 목록은 공고문에 쓰이는 한국어 표현을 직접 작성한 것으로, 학습된 파라미터가 아니다.

## 4. 임계값·분기 선택 과정

일부 분기(예: 기업규모 라벨 동점 시 처리, 공고문 금액 채택 허용 범위 0.6~1.6배)는
**대회 제공 dev 200건으로 교차확인**하여 선택했다. 규칙 탭 2) 허용 항목의
"dev 200건(라벨 포함)을 어떤 용도로든 사용 가능" 및 "모델 출력에 대한 후처리·규칙 기반 보정 허용"에 해당한다.
학습된 가중치가 아니라 사람이 읽고 고른 분기이며, 선택 근거는 `SOLUTION.md` 에 수치와 함께 적어 두었다.

## 5. 개발 도구

- 파이프라인 코드는 Anthropic Claude 를 코딩 보조 도구로 사용하여 작성했다.
  설계 판단·법령 대조·임계값 채택은 제출자가 검토·확정했다.
- 제출되는 추론 코드에는 외부 LLM·외부 API 호출이 없다(규칙 2-2 금지 항목).
